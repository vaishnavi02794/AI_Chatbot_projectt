# 🤖 AI Chatbot

A simple AI chatbot built using Python and Google's Gemini API. This project accepts user input from the terminal and generates AI-powered responses. I created this project to learn how to integrate APIs, work with Python, and understand the basics of conversational AI.

---

## 📖 About the Project

This chatbot interacts with users through the command line. It takes a question as input, sends it to the Gemini API, and displays the generated response. The project helped me understand API integration, user input handling, and Python programming.

---

## ✨ Features

- Interactive command-line chatbot
- AI-generated responses using Google Gemini
- Simple and easy-to-understand code
- Beginner-friendly project structure
- Exit option to end the conversation

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/vaishnavi02794/AI_Chatbot_projectt.git
```

### Go to the project folder

```bash
cd AI_Chatbot_projectt
```

### Install the required package

```bash
pip install google-genai
```

### Add your API key

Open `chatbot.py` and replace:

```python
api_key = "YOUR_API_KEY"
```

with your own Gemini API key.

### Run the project

```bash
python chatbot.py
```
